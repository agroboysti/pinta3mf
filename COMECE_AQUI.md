# Como continuar no Claude Code

1. Descompacte esta pasta em um lugar fácil, por exemplo `C:\Projetos\pinta3mf`.
2. Coloque o modelo de teste dentro dela (ex.: `knitted_santa_3d_model.zip`).
3. Abra o terminal nessa pasta e rode:

```
claude
```

O Claude Code lê o `CLAUDE.md` sozinho e já sabe tudo o que foi feito.

4. Cole esta primeira mensagem:

```
Leia o CLAUDE.md. Quero terminar o Pinta3MF.
Primeiro: gere o 3MF do knitted_santa_3d_model.zip com o core.js e descubra se o Bambu Studio
desta máquina mostra a pintura ao importar. Ache o Bambu Studio instalado, veja se a linha de
comando dele ajuda a testar, e se precisar procure um .3mf salvo pelo próprio Bambu Studio no
meu computador para copiar a estrutura de projeto. Me peça para abrir no Bambu e mandar print
quando não der para testar sozinho.
Depois disso: crie um programa para Windows em que eu arrasto o modelo e sai o 3MF pintado.
```
